## MXB Local for Windows

An independent personal fork of [Frostn1/mxb-app](https://github.com/Frostn1/mxb-app), based on v0.20.6. The upstream MIT license and attribution are retained.

### Install or update

Download **MXB.Local_0.20.6-local.4_x64-setup.exe** below, close MXB Local, then run it. Existing MXB Local settings are retained. You no longer need the Microsoft Visual C++ package installed. GitHub's automatic Source code downloads contain the source, not the Windows installer.

### What's new in local.4

This release works through an independent technical audit of local.3.

**Reliability**
- If a saved login can't be decrypted, for example after an administrator resets your Windows password or you copy settings to another PC, you are signed out of that one service. Before, the app silently replaced all your settings with defaults. A settings file the app can't read is now kept as `config.json.bak`.
- The app includes the Microsoft C and C++ runtime parts it uses, so it starts on a PC that has never had the Visual C++ package installed.
- "Delete my data" when uninstalling is no longer refused just because the original MXB App is installed on the same PC.
- An archive that would unpack to more than 20 times its own size (at least 4 GB is always allowed) is refused instead of filling your disk.

**Privacy**
- Nothing is sent to the original developer's service at startup.
- The game server list you see on the Online screen is no longer uploaded to the original developer's service.
- The supporters list is no longer downloaded from GitHub each time Settings opens.
- Friends presence is off unless you turn it on.
- Images in shop and hub mod descriptions load only from the mod sites themselves, so a mod author can't learn who viewed their page.
- [docs/privacy-local.md](https://github.com/Crab-Krab/mxb-local/blob/main/docs/privacy-local.md) lists everything the app still contacts, and when.

**Security**
- The in-app Visual C++ installer, which downloaded a program and ran it with administrator rights, is disabled with the other native downloads.
- Unused code that was still built is removed: the updater plugin, a second copy of the MEGA client and old voice-chat sources. 23 fewer third-party packages, and 6 fewer advisory matches.

**Cleanup**
- Settings no longer shows the update and survey switches, which did nothing in this fork.

### How it was checked

Every build now runs all checks: about 1,900 Rust tests, the frontend unit tests, typecheck, lint and two browser test suites. local.3's release ran 27 of them. The build also fails if the app imports the Visual C++ runtime DLLs.

The attached **SECURITY-REVIEW.md** explains the remaining advisory findings and which APIs and platforms they concern. Dependency findings, the Windows dependency graph, the production frontend inventory and exact lockfiles are attached. A completed scan is not a zero-vulnerability certification.

Not yet tested by hand: installing and opening local.4 on a freshly installed Windows PC, and the settings recovery on a real profile.

### Limits

- Unsigned personal build, not an official Frost/mxbsecure release. Automated checks do not guarantee the absence of vulnerabilities.
- Popularity covers the site's top 100 overall, narrowed to the selected category. Newest and Oldest browse the full category.
- Private upstream integrations and some store, geometry and server features are unavailable. Optional online features still depend on their services.
- Updates are installed manually from this fork.
