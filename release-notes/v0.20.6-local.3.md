## MXB Local for Windows

An independent personal fork of [Frostn1/mxb-app](https://github.com/Frostn1/mxb-app), based on v0.20.6. The upstream MIT license and attribution are retained.

### Install or update

Download the installer below, close MXB Local, then run it. Existing MXB Local settings are retained. GitHub's automatic Source code downloads contain the source, not the Windows installer.

### Included

- Sanitized remote descriptions and a Content Security Policy.
- Patched TLS dependencies and Windows DPAPI protection for saved credentials.
- Automatic usage/game-memory reporting disabled; upstream app updates and native game-DLL installation blocked.
- Permanent first-run setup completion fix.
- MXB popularity browsing using the site's current public ranking, with clearer category-limit messages.
- MXB Local branding with an upstream source credit.
- Built-in voice chat excluded, including microphone access, voice commands, audio codecs and WebRTC dependencies.
- Setup component browser tests and archive path/link safety regressions.

The attached **SECURITY-REVIEW.md** explains the current advisory findings and which APIs/platforms they concern. Machine-readable dependency findings with source references, the Windows dependency graph, production frontend inventory and exact lockfiles are attached for review. A completed scan is not a zero-vulnerability certification.

Track download/install, gameplay, uninstall and installer replacement were manually verified with local.2. The local.3 build has the automated checks linked below; its setup browser tests simulate native APIs.

### Limits

- Unsigned personal build, not an official Frost/mxbsecure release. Automated checks and local smoke tests do not guarantee the absence of vulnerabilities.
- Popularity covers the site's top 100 overall, narrowed to the selected category. Newest and Oldest browse the full category; a category can have no entries in the top 100.
- Private upstream integrations and some store/geometry/server features are unavailable. Optional online features still depend on their services.
- Updates are installed manually from this fork.
