## MXB Local for Windows

An independent personal fork of [Frostn1/mxb-app](https://github.com/Frostn1/mxb-app), based on v0.20.6. The upstream MIT license and attribution are retained.

### Install or update

Download **MXB.Local_0.20.6-local.5_x64-setup.exe** below, then run it. If MXB Local is already installed, ensure it is closed before proceeding. Existing MXB Local settings are retained. GitHub's automatic Source code downloads contain the source, not the Windows installer.

### What's new in local.5

local.5 removes what was left of FrostMod ("Game Integration"), the original app's in-game component. MXB Local has never installed it, but local.4 still offered it.

**Fixes**
- After setup, local.4 could open a "Game Integration" dialog that couldn't be closed by pressing Escape or clicking outside it. Its Enable button then failed with an error. The dialog no longer appears.
- local.4 asked GitHub for the latest FrostMod release when it started and every 30 minutes. GitHub saw your IP address. Nothing was downloaded, but the request had no purpose, and the privacy note wrongly said there were no update checks. local.5 makes no such request, and [docs/privacy-local.md](https://github.com/Crab-Krab/mxb-local/blob/main/docs/privacy-local.md) now records the local.4 behaviour.

**Hidden because they only work with FrostMod**
- Game Integration status in the top bar, its Settings section, its tour step and its runtime warning.
- Paint sync, the "Instant preset refresh" setting, the protected-paints prompt and the Servers tab's "fix the in-game server browser" item.

**Unchanged**
- Model swaps, sound mods and ReShade presets work as before. Their folders (`FrostMod Models`, `FrostMod Sounds`, `FrostMod ReShade`) keep their names, because existing installs and the original app use them.
- No dependency changes since local.4.

### How it was checked

Every build runs all checks: about 1,900 Rust tests, the frontend unit tests, typecheck, lint and two browser test suites, plus the Visual C++ runtime import check. The tour test now confirms the Game Integration step never appears.

Not tested by hand: the app's screens on a real PC, installing on a freshly installed Windows PC, and the settings recovery on a real profile.

The attached **SECURITY-REVIEW.md** explains the remaining advisory findings and which APIs and platforms they concern. A completed scan is not a zero-vulnerability certification.

### Limits

- Unsigned personal build, not an official Frost/mxbsecure release. Automated checks do not guarantee the absence of vulnerabilities.
- Popularity covers the site's top 100 overall, narrowed to the selected category. Newest and Oldest browse the full category.
- Private upstream integrations and some store, geometry and server features are unavailable. Optional online features still depend on their services.
- Updates are installed manually from this fork.
